Instruksi :

Membuat aplikasi Flutter yang menarik data dari salah satu public API yang tersedia secara gratis, kemudian tampilkan datanya dalam satu halaman penuh yang dirancang sendiri. bebas menentukan data apa saja yang ingin ditampilkan dan bagaimana cara penyajiannya selama data benar-benar berasal dari API dan bukan hardcode, lalu pisahkan kode Anda ke dalam tiga folder yaitu models untuk class data immutable dengan factory fromJson, services untuk satu-satunya file yang boleh memanggil http, dan ui untuk tampilan yang terbagi lagi antara screens sebagai halaman pengatur state dan widgets sebagai komponen penerima data lewat constructor, serta tangani tiga kondisi loading, sukses, dan error dengan pesan yang jelas dan tombol coba lagi, dan aplikasi wajib lolos flutter analyze tanpa error. 

pada projek saya ini, saya menggunakan API Cuaca Publik
